Contents of Abagen folder are used to run Abagen package to get parcel level AHBA data for Schaefer 100/200 atlases.
(See https://abagen.readthedocs.io/en/stable/citing.html for details about abagen package/citing details)

Contents of Correlations folder contain functions to run correlations between gene data and 13C atlases using brainSMASH package to account for spatial autocorrelation
(See https://brainsmash.readthedocs.io/en/latest/ for details about brainSMASH package)

SpinTestScripts folder contains scripts and functions to control for spatial autocorrelation using the spin test method, with code for spin permutations used with minor
modifications from https://github.com/frantisekvasa/rotate_parcellation.

parametricNullDistributionScripts folder contains scripts and functions to control for spatial autocorrelation using brainSMASH parametric technique.
(See https://brainsmash.readthedocs.io/en/latest/ for details about brainSMASH package)
